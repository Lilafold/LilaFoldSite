LilaFold: Small models. Serious work.

LilaFold (LilaFold Labs) builds small, specialised AI models trained for one job each—compact enough to run privately in our cloud first, then on modular NPU hardware you own.

"Depth over breadth: a specialised model with 3.3 million parameters can match 1.5B–3B general LLMs on its target task while running on a standard CPU."

Featured research: Lala L1-Lite Ablation (3.3M parameters) reaches 0.89 PR-AUC across 12 unseen lab campaigns (76,312 Linux OCSF events) and processes ~28,000 events/s on a desktop CPU in ~15 seconds, compared to 11–30 minutes on an RTX 4090 for 1.5B–3B LLMs. Checkpoints and code are on Hugging Face and GitHub.

Built for the job, not for everything

General models are huge because they try to know everything. Ours are trained for one field each, so they can be small, fast and cheap to run.

  • Depth over breadth: A model trained for one field spends its capacity where it counts.
  • Efficient per token: Fewer parameters mean less memory and energy for every answer.
  • Private by design: Small enough to run on hardware you control, not only in someone else's data centre.

In development: Cybersecurity (log triage, threat explanations, alert summaries). Exploring next: freight and logistics, software engineering, forecasting, and research workflows.

LilaFold Cloud

Our models behind a simple API. Pay per request or subscribe. No GPUs to rent or manage.

Modular NPU Hardware

NPU modules that connect together. Start with one base unit and add more as your workload grows. NPUs (neural processing units) are chips built specifically for AI as a lower-power, lower-cost alternative to GPUs.

Roadmap: Where LilaFold is going

  1. Now — Specialised models: Research efficient architectures and build our first model, Lala L1-Lite, for cybersecurity.
  2. Next — Cloud early access: Open the LilaFold API to early users, with usage pricing and subscriptions.
  3. Then — Two-module prototype: Show models running across connected NPU modules.
  4. Later — Hardware pilots: Work with design partners, refine the modules and move toward manufacturing.
